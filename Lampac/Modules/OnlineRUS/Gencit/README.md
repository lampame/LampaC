# Gencit

Онлайн-источник **Gencit** для сериалов. Поиск плейлиста выполняется по **Kinopoisk ID** или **IMDb ID**.

Для работы требуется **SOCKS-прокси с IP-адресом РФ**. Потоки проходят через **streamproxy**.

## Интерфейс

**`IModuleLoaded`**, **`IModuleOnline`**.

## Ограничения

- Балансер предназначен **только для сериалов**.
- Для получения данных Gencit требуется доступ через **SOCKS-прокси РФ**.
- Глобальный поиск (`IModuleOnlineSpider`) не используется.

## Качество

По умолчанию в Online API отображается **`~ 1080p`**.

Если API Gencit сообщает **2160p**, балансер учитывает качество **4K** при проверке источника. Поток отдаётся в **HLS** с автоматическим выбором качества.

## Конфигурация

Секция в `init.conf`: **`Gencit`** (`OnlinesSettings`).

По умолчанию: **`streamproxy = true`**, **`displayindex = 535`**, **`stream_access = apk,cors,web`**.

Для работы через российский SOCKS5-прокси необходимо включить прокси для запросов и потоков. Пример настроек:

```json
{
  "useproxy": true,
  "proxy": {
    "list": [
      "socks5://000.000.000.00:0000"
    ]
  },
  "useproxystream": true
}
```

- **`useproxy`** — использовать прокси для запросов балансера.
- **`proxy.list`** — список SOCKS5-прокси; для Gencit нужен прокси с **IP РФ**.
- **`useproxystream`** — использовать прокси также для видеопотока.
