Модуль **TorrServer** в Lampac NextGen запускает торрент-сервер как управляемый подпроцесс и проксирует все его запросы через префикс `/ts/`. Для каждой сессии генерируется случайный пароль, поэтому вам не нужно заботиться об аутентификации самого TorrServer.

## Как это работает

<Steps>
  <Step title="Запуск подпроцесса">
    Lampac автоматически запускает TorrServer при старте сервера. Процесс управляется изнутри приложения, поэтому не требуется ручная установка или настройка TorrServer отдельно.
  </Step>
  <Step title="Проксирование запросов">
    Все запросы к TorrServer доступны через префикс `/ts/`. Например, веб-интерфейс TorrServer открывается по адресу `http://<host>:9118/ts/`.
  </Step>
  <Step title="Случайный пароль за сессию">
    Для каждой сессии Lampac генерирует случайный пароль. Это исключает риск несанкционированного доступа к TorrServer извне.
  </Step>
</Steps>

## Включение и отключение

`manifest.json` разрешает загрузку модуля, но starter-файл `config/example.init.conf` добавляет `TorrServer` в `SkipModules`. Чтобы включить его, удалите это имя:

```json
{
  "BaseModule": {
    "SkipModules": []
  }
}
```

<Note>
  Сохраняйте каталог `data/ts/` на persistent volume, чтобы бинарник, настройки и данные TorrServer переживали пересоздание контейнера.
</Note>

## Конфигурация

Дополнительные параметры TorrServer можно задать в секции `TorrServer` файла `init.conf`. Пример структуры:

```json
{
  "TorrServer": {
    "releases": "latest",
    "tsport": 9085,
    "checkfile": true
  }
}
```

Если секция отсутствует, используются defaults из `ModInit`: release `MatriX.135`, внутренний порт `9085` и проверка бинарника. Внешний доступ по-прежнему идёт через `/ts/*`.

## Использование в Lampa

В клиенте Lampa TorrServer подключается автоматически через плагин `torrserver`. Убедитесь, что в `init.conf` в разделе `LampaWeb.initPlugins` установлено `"torrserver": true`:

```json
{
  "LampaWeb": {
    "initPlugins": {
      "torrserver": true
    }
  }
}
```

После этого в карточке фильма или сериала в Lampa появится возможность открыть контент через TorrServer.
