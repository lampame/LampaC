Модуль адаптирует Online/SISI выдачу под клиент ForkPlayer.

## Состояние

Выключен в `base.conf` SkipModules.

## Маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/fxml` | Плейлисты |
| `GET` | `/fxml/tmdb` | TMDB-адаптер |
| `GET` | `/fxml/cub` | CUB-адаптер |

## Конфигурация

```json
{
  "BaseModule": { "SkipModules": [] }
}
```

<Danger>
  Не публикуйте этот модуль в интернет без аутентификации, WAF и ограничения сети.
</Danger>

Проверка: `curl -fsS http://127.0.0.1:9118/fxml`
