Не включайте WebLog на публичном адресе. DatabaseEditor использует ту же форму входа `/weblog/auth`.

## Состояние

Выключен в `base.conf` SkipModules. Требует root `passwd`.

## Маршруты

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/weblog` | UI |
| `GET` | `/weblog/auth` | Вход |

## Конфигурация

```json
{
  "BaseModule": { "SkipModules": [] }
}
```

<Danger>
  Не публикуйте этот модуль в интернет без аутентификации, WAF и ограничения сети.
</Danger>

Проверка: `curl -fsS http://127.0.0.1:9118/weblog`
