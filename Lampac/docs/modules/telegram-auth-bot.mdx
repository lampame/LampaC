TelegramAuthBot — long-polling бот: привязка UID и устройства, админ-команды. Публичного HTTP UI нет: бот сам вызывает [TelegramAuth](/modules/telegram-auth).

## Состояние

Выключен в `base.conf` `SkipModules` и `manifest.enable: false`. Скопируйте `Modules/Community/TelegramAuthBot/init.merge.example.json`, включите манифест и уберите `TelegramAuthBot` из `SkipModules`.

`mutations_api_secret` должен совпадать с TelegramAuth.

```json
{
  "TelegramAuthBot": {
    "enable": true,
    "bot_token": "TOKEN",
    "mutations_api_secret": "SECRET"
  }
}
```

<Warning>
  Не коммитьте `bot_token`. Храните его только в `init.conf` на сервере.
</Warning>

После запуска проверьте журнал: бот должен начать long polling без ошибок авторизации Telegram API. Проверка HTTP-стороны — через [TelegramAuth](/modules/telegram-auth):

```bash
curl -fsS "http://127.0.0.1:9118/tg/auth/status?uid=DEVICE_UID"
```
