Группа **OnlineENG** включает 10 провайдеров западного контента. Каждый доступен через `/lite/{provider}`.

| Провайдер | Сервис |
| --- | --- |
| `AutoEmbed` | AutoEmbed |
| `HydraFlix` | HydraFlix |
| `MovPI` | MovPI |
| `PlayEmbed` | PlayEmbed |
| `RgShows` | RgShows |
| `SmashyStream` | SmashyStream |
| `TwoEmbed` | TwoEmbed |
| `VidLink` | VidLink |
| `VidSrc` | VidSrc |
| `Videasy` | Videasy |

```json
{
  "BaseModule": {
    "LoadModules": ["OnlineENG"]
  }
}
```

Украинские источники вынесены на [OnlineUKR](/providers/ukrainian).
