Группа `OnlineRUS` загружается с модулем Online. Отключите всю группу через `SkipModules: ["OnlineRUS"]`.

| Провайдер | Примечания |
| --- | --- |
| `CDNvideohub` | CDN |
| `Collaps` | Обычный и DASH |
| `FanCDN` | fanserial |
| `FlixCDN` | Фильмы и сериалы |
| `Gencit` | `/lite/gencit` |
| `HDVB` | Балансер |
| `Kinobase` | Релизы |
| `Kinogo` | Классический источник |
| `Kinotochka` | Разнообразный контент |
| `LeProduction` | Производственный контент |
| `Mirage` | Мультиозвучка |
| `Phantom` | Регулярные обновления |
| `PizdatoeHD` | HD |
| `RutubeMovie` | Rutube |
| `Spectre` | Актуальные релизы |
| `VeoVeo` | Офлайн `data/veoveo.json` |
| `Vibix` | Библиотека |
| `VideoDB` / `Videoseed` | `/lite/videodb`, `/lite/videoseed` |
| `VkMovie` | ВКонтакте |
| `Zetflix` / `ZetflixDB` | Два варианта |
