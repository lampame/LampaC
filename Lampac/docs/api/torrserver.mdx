Starter-конфиг исключает модуль. Пароль сессии случайный.

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/ts.js`, `/ts/js/{token}` | Plugin |
| `GET` | `/ts/{*suffix}` | Прокси TorrServer |
| `GET` | `/ts/torznab/{suffix}` | Torznab |

Конфиг: [TorrServer](/modules/torrserver).
